# Arc swap integration research

- LI.FI chain docs: https://docs.li.fi/introduction/chains
  - The REST chain list is the authoritative current support surface. A read-only LI.FI quote request made during this task returned HTTP 400 with `Chain 5042 is not supported`, so LI.FI must remain a fallback and must not be treated as the only Arc swap path.
- Uniswap SDK Core Arc address map: https://raw.githubusercontent.com/Uniswap/sdks/main/sdks/sdk-core/src/addresses.ts
  - Arc chain ID: 5042.
  - Arc v3 factory: `0xf0db7b58379503491d857db50ac9ece64c653918`.
  - Arc v3 Quoter: `0x7dfd4f31be6814d2906bde155c3e1b146eac1468`.
  - Arc SwapRouter02: `0x53bf6b0684ec7ef91e1387da3d1a1769bc5a6f77`.
  - Arc v4 Quoter: `0x8dc178efb8111bb0973dd9d722ebeff267c98f94` (not the v3 Quoter).
- Arc/UniswapX playbook: https://raw.githubusercontent.com/Uniswap/UniswapX/main/playbook/chains/arc.md
  - Confirms Arc 5042 routing surfaces and the distinction between v3/v4 addresses.
- Arc RPC docs: https://docs.arc.io/arc/references/rpc-endpoints
  - The currently published docs page describes testnet endpoints and explicitly says mainnet endpoints are published separately when available. The attempted public `https://arc-rpc.transferto.xyz/` read-only Quoter call was blocked by Cloudflare HTTP 403, so live quote verification must use the connected wallet's RPC or a valid mainnet RPC configured by the user.
